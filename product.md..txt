# Задание 2. IT-продукт

## Название продукта
**StudyFlow — планировщик учёбы**

## 1. Что это за продукт?

StudyFlow — веб-приложение, которое помогает школьникам и студентам планировать учёбу. В нём можно записывать домашние задания, устанавливать сроки выполнения, распределять дела по предметам и отслеживать свой прогресс.

Главная идея приложения — собрать учебные задачи в одном месте, чтобы пользователю было проще организовать своё время.

## 2. Кто будет пользоваться приложением?

Основные пользователи StudyFlow:
- школьники;
- студенты колледжей и университетов;
- преподаватели, которые хотят наглядно показывать сроки выполнения заданий.

В первую очередь приложение рассчитано на учащихся, которым нужно одновременно следить за заданиями по нескольким предметам.

## 3. Какую проблему решает продукт?

Домашние задания и сроки их сдачи часто записаны в разных местах: в дневнике, переписках, заметках или на отдельных листках. Из-за этого легко забыть о важной работе или неправильно распределить время.

StudyFlow решает эту проблему: все задания хранятся в одном списке, отсортированы по срокам и предметам. Пользователь может заранее увидеть, что ему нужно сделать.

## 4. Основные возможности приложения

1. **Регистрация и вход.** Пользователь создаёт аккаунт и входит в приложение.
2. **Добавление заданий.** Можно указать название, предмет, описание и дату сдачи.
3. **Список и фильтры.** Задания можно сортировать по предмету, сроку или статусу.
4. **Напоминания.** Приложение напоминает о приближающихся сроках.
5. **Отметка о выполнении.** Пользователь отмечает готовые задания, чтобы видеть свой прогресс.
6. **Календарь.** Все сроки отображаются в календаре, что помогает планировать неделю.

## 5. Кто будет создавать приложение?

Для разработки StudyFlow понадобится команда из нескольких специалистов:

- **Менеджер проекта (Project Manager)** — планирует работу команды, распределяет задачи и следит за сроками.
- **UX/UI-дизайнер** — продумывает внешний вид приложения и делает интерфейс удобным.
- **Frontend-разработчик** — создаёт страницы и элементы, с которыми взаимодействует пользователь.
- **Backend-разработчик** — разрабатывает серверную часть, обрабатывает запросы и организует работу с базой данных.
- **Тестировщик (QA-инженер)** — проверяет приложение, ищет ошибки и сообщает о них разработчикам.
- **Специалист по базам данных** — проектирует структуру хранения пользователей и учебных заданий.

## 6. Как работает функция добавления задания?

Рассмотрим добавление нового домашнего задания.

### Интерфейс (UI)
Пользователь открывает раздел «Мои задания», нажимает кнопку «Добавить» и заполняет форму: вводит название задания, выбирает предмет и указывает дату сдачи. Затем нажимает «Сохранить».

### Сервер (Backend)
После нажатия кнопки приложение отправляет данные на сервер. Сервер проверяет, заполнены ли обязательные поля и корректна ли дата. Если данные подходят, сервер подготавливает запись для сохранения.

### Данные
В базе данных создаётся запись с идентификатором задания, идентификатором пользователя, названием, предметом, сроком сдачи и статусом выполнения. Например:

```json
{
  "id": 15,
  "userId": 1,
  "title": "Подготовить презентацию по биологии",
  "subject": "Биология",
  "dueDate": "2026-11-12",
  "completed": false
}
```

### Результат
Сервер возвращает ответ об успешном сохранении. Новое задание появляется в списке пользователя с указанным сроком сдачи. Если данные заполнены неправильно, приложение показывает сообщение с просьбой исправить ошибку.

## Вывод

StudyFlow помогает организовать учебные задачи и не забывать о сроках. В приложении предусмотрены основные функции для планирования, а команда специалистов отвечает за его дизайн, разработку, хранение данных и проверку качества.
